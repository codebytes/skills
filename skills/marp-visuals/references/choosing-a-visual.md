# Choosing a Visual

Start with the audience question, not a preferred tool.

| Audience question | Visual |
|---|---|
| Which category is larger? | Sorted bar chart |
| How did a value change over time? | Line chart |
| How do two options differ? | Comparison slide or grouped bars |
| What happens next? | Flowchart |
| Who communicates with whom? | Sequence diagram |
| What states can this system enter? | State diagram |
| How are components related? | Dependency graph |
| Where does data live? | Architecture or data-flow diagram |
| What are the exact values? | Table |

Use Mermaid for standard structural diagrams. Use `drawio-diagrams` when the
diagram needs branded shape libraries, visual editing, custom geometry, or
precise manual layout.

Do not make a chart when one number or one sentence communicates the point
better.
