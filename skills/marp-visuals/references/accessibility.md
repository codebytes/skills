# Visual Accessibility

- Add `<title>` and `<desc>` elements to generated SVG.
- Use meaningful Markdown alt text when embedding the asset.
- Do not rely on hue alone; combine color with labels, shapes, or line styles.
- Target 4.5:1 contrast for normal text and 3:1 for large labels.
- Keep chart labels at least 16px in a 1280x720 SVG.
- Include units and explain abbreviations.
- Directly label important lines, bars, or nodes.
- Avoid dense node graphs and tiny legends.
- Preserve the source data or diagram definition for users who need an
  alternative representation.
