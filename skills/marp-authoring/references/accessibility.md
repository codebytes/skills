# Accessibility

- Give every informative image meaningful alt text.
- Use empty alt text only for purely decorative images.
- Do not encode meaning with color alone.
- Target at least 4.5:1 contrast for normal text and 3:1 for large text.
- Keep body text large enough for projection; avoid shrinking an entire slide
  to solve overflow.
- Use direct labels on charts when possible.
- Include units, time ranges, and data sources.
- Preserve logical reading order in columns and custom HTML.
- Use descriptive link text instead of raw URLs when space allows.
- Avoid autoplay, rapid animation, or transitions required to understand content.
- Check that exported PDF text remains selectable unless an image-only export was
  explicitly requested.
